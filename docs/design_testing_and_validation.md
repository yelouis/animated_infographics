# Testing & Validation

This document owns: the **fixtures**, every **gate** in the battery and the **falsification** that proves each gate can fail, the **E2E** and **offline** gates, the **performance budget**, and which **artefacts get committed**.

**The standard, inherited from the user's previous projects, where each rule was paid for with a shipped defect:**
- **A gate must be able to fail.** For every gate, name the input that turns it red, run it once, and record the red run next to the green one.
- **Read exit codes bare.** `cmd | tail` reports `tail`'s exit status, which is always 0.
- **A gate that did not run is not a pass.** If a model, device or tool is missing, the baseline says **NOT RUN** and why.
- **A validation that leaves no artefact is a claim.** Reports, contact sheets and golden stills are committed.
- **A search used to prove absence must not encode an incidental convention** (quote style, extension, naming). Corroborate an absence a second way (a count, a listing).
- **A check over a hand-written list only verifies the list.** Pair it with a containment check against what is actually used.
- **Measure; do not estimate.** Every bar below is a number; record the measured value, not "pass".

## 2. Test layers

**Unit (`uv run pytest -m "not slow"`, no models, < 60 s total).** Must include at least:

| Module | Cases that must exist |
|---|---|
| `timing/frames.py` | round-half-up (`ms_to_frame(550) == 17`, `ms_to_frame(516) == 15`); a beat starting at 5,000 ms gets scene start frame **144** (`LEAD_MS` applied); `LEAD_MS` never makes a start negative or non-increasing; scenes tile `[0, duration_frames)` |
| `timing/beats.py` | a 900 ms beat merges into the smaller-combined neighbour; a 9,000 ms beat splits at a comma boundary in preference to a longer plain gap far from the middle; beat 0 is never merged; a property test over 500 random word streams: tiling holds, every beat k ≥ 1 is ≥ 1,500 ms, and every beat is ≤ 8,000 ms unless the log records "no valid split" |
| `timing/captions.py` | the 3-word cap; the 22-char cap; comma break at ≥ 2 words; no page crosses a sentence; the gap/tail rule; a 23-char word alone on its page |
| `planner/grounding.py` | `"2.3 million"` yields both 2.3 and 2.3e6; `"Twenty-one"` → 21; `"$1,500"` → 1500; `"a thousand"` → 1000; **`stat 1500` is rejected against `"about 150 were injured"`**; the verbatim span rejects a paraphrase and a mid-word start |
| `planner/validate.py` | one failing and one passing case per template-specific rule in `design_templates.md` |
| `textfit.py` | a string that fits at `size_min` and one that needs `max_lines + 1` |
| `planner/voice.py` | first-person rate on all four fixtures equals the measured values in `design_planner.md` §10 (±0.01); a text whose only "I" is inside double quotes → third person; the tag cases `I (26F)` → female, `My (34M) wife (33F)` → male, `Me [F29]` → female, `My sister (22F) said` → no tag; **all 23 evidence cases** in the table in `design_planner.md` §10 (7 accepted, 16 rejected), each as its own parametrised test id; evidence not in the text → rejected; `unknown` with evidence → evidence repaired to null; the full decide() truth table (perspective × gender, 6 rows: only first_person+female → `af_heart`); `--voice am_michael` makes **zero** backend calls, counted at the backend's entry point; `--voice bm_george` → exit 2; a backend that fails 3 times → `unknown`/`no_evidence`/`am_michael`, never an exception |
| `jobs.py` | every refusal in `design_system_architecture.md` §5 returns exit 3; an edit after approval flips `plan_sha256` |
| `contracts/` | an unknown key is rejected (`extra="forbid"`); `schema_version: 2` is rejected |
| `planner/llm.py` | retry protocol against `httpx.MockTransport`; cache key stable across dict ordering; the seed increments per attempt |

**Integration (`uv run pytest -m slow`, real models).** Kokoro transcript invariants and exact sentence offsets (the sum of samples equals the WAV length to the sample); Whisper WER ≤ 8% on the `say` fixture (normalise: lowercase, strip punctuation, spell out nothing); Whisper-vs-Kokoro word-start error median ≤ 80 ms and p95 ≤ 250 ms; Ollama structured-output conformance **20/20** on a toy schema with an `enum` and a `maxLength`; the **voice stage on all four fixtures** matches the expected `voice`/`reason`/`evidence_contains` (and `molasses_flood`/`emu_war` make zero LLM calls in that stage); two inline snippets through the real model: `"My sister is a nurse and my mom is a teacher. I work nights at the hospital and I love my job."` → `unknown` → `am_michael`, and `"As a dad of three, I never thought I'd be asked to leave a playground."` → `male` → `am_michael`; mflux generates one fixture image and the second call is a cache hit in < 1 s.

**Renderer (`npm --prefix renderer test`, vitest).** Pure helpers: the map framing math (min-span expansion, 25% padding); caption word-activity lookup; avatar parameter → shape selection.

## 3. The battery (`scripts/battery.sh`)

Runs every gate **bare**, one after another, prints a table of gate / exit code / key number, and exits non-zero if any gate failed. `--fast` runs G1–G10 and G14 (no heavy models). The execution guide's §1 is the recorded baseline of this table.

| # | Gate | Command | Green means | Falsify it by (must go red) |
|---|---|---|---|---|
| G1 | Lint | `uv run ruff check .` | exit 0 | adding an unused import |
| G2 | Format | `uv run ruff format --check .` | exit 0 | mis-indenting one line |
| G3 | Types | `uv run mypy src` | exit 0 | returning `str` from a function annotated `int` |
| G4 | Unit | `uv run pytest -q -m "not slow"` | exit 0, **N passed** (record N) | changing `LEAD_MS` to 0 (frames tests fail) |
| G5 | TS types | `npm --prefix renderer run typecheck` | exit 0 | a misspelt icon in the allow-list (`iconMap.ts` fails) |
| G6 | TS lint | `npm --prefix renderer run lint` | exit 0 | an unused variable |
| G7 | TS unit | `npm --prefix renderer test` | exit 0, N passed | breaking the min-span constant |
| G8 | Schema sync | `./scripts/check_schema_sync.sh` | exit 0 | hand-editing one generated file; **also** emptying one generated file (must be exit 1, not a vacuous pass) |
| G9 | Renderer purity | `./scripts/check_renderer_purity.sh` | exit 0 | `useCurrentFrame()` in a template |
| G10 | Gallery | `./scripts/check_gallery.sh` | exit 0: 0 overflows, goldens within tolerance, hold motion present | a `max` fixture string 20 chars longer (overflow); a template frozen during hold (motion check) |
| G11 | Integration | `uv run pytest -q -m slow` | exit 0, N passed | swapping the WER bar to 0% |
| G12 | E2E | `./scripts/e2e.sh` | exit 0 (§4) | skipping `approve` (render must refuse, and the script must notice) |
| G13 | Offline | `./scripts/check_offline.sh` | exit 0 (§6) | removing the `deny network-outbound` line (its own self-check must fail) |
| G14 | Doctor | `uv run infographics doctor` | exit 0 | `ollama stop` / an unpulled model name → exit 4 naming it |

**Gallery gate details:** render every template × {`min`,`typical`,`max`} at its hold frame (frame 60 of a 150-frame synthetic scene whose fixture specifies `timing` explicitly) → `artifacts/gallery/<template>__<variant>.png`.
- (a) `overflow.json` empty.
- (b) vs `renderer/goldens/<template>__<variant>.png`: a pixel "differs" when any channel differs by > 16; fail when > **0.5%** of pixels differ.
- (c) **hold motion:** frames 60 and 105 of the `typical` fixture differ in > **0.1%** of pixels.

Goldens change only via `./scripts/check_gallery.sh --update`, and the commit body must name every golden that changed and why. The agent **opens and looks at** every new golden before committing it. A golden that captures a broken frame makes the breakage the standard.

## 4. E2E gate (`scripts/e2e.sh`)

Uses a fresh `--jobs-dir` under `artifacts/e2e/<timestamp>/`. Steps and assertions, each on the **exit code**:

1. `new fixtures/scripts/molasses_flood.txt --music fixtures/music/test_bed.wav --sfx-dir fixtures/sfx` → **0**; `status` shows `awaiting_review`; `preview/contact_sheet.png` exists and is non-blank; the log mentions ignoring `clap`; `voice.json` says `am_michael` / `third_person`, and `preview/storyboard.md`'s first line is the voice line.
2. `render` → **3** (not approved).
3. `approve` → **0**. Then change one character of one scene's text in `storyboard.json` (with `jq`; the change must keep the plan valid) → `render` → **3** (plan changed).
4. `preview` → **0** · `approve` → **0** · `render` → **0**; `out/verify.json` all checks true.
5. **Sync probe:** `render.ts media --sync-probe` for the same job → `artifacts/.../sync.mp4`. For each scene k ≥ 1, pixel (24, 24) at `start_frame − 1` and `start_frame + 1` flips between black (luma < 40) and white (luma > 215). Record the number of scenes checked.
6. `new fixtures/audio/molasses_flood_say.m4a` → approve → render → **0** each, and `verify.json` passes.
7. `story_recipe_box.txt`, `story_room_12.txt` and `emu_war.txt` through to render → **0**; their `voice.json` files match the expectations in §1 (`af_heart`/`llm`, `am_michael`/`no_evidence`, `am_michael`/`third_person`); record stage timings for `story_recipe_box` (§5) and `emu_war` (`design_audio_and_timing.md` §10).
7b. `new fixtures/scripts/story_recipe_box.txt --voice am_michael` → **0**; `voice.json` has `source: "flag"`, and that job's `logs/voice.log` records zero LLM calls.
8. **Determinism:** `new molasses_flood.txt` again into a second job with a warm cache → `bible.json`, `beats.json`, `storyboard.json` **byte-identical** to step 1's.

Writes `docs/evals/e2e_<YYYY-MM-DD>.md` (committed): every exit code, the `verify.json` contents, sync-probe counts, stage timings, and the contact sheets copied to `docs/evals/assets/<YYYY-MM-DD>/`. **MP4s are not committed** (size); the report names their paths and SHA-256.

## 5. Performance budget (M4 Max, 64 GB), measured on `story_recipe_box` (~3 min, the longest fixture)

| Span | Bar | Conditions |
|---|---|---|
| `new` → `awaiting_review` | ≤ **6.5 min** | Ollama running with the model *not yet loaded*; LLM cache and image cache **empty** |
| `render` | ≤ **3.5 min** | |
| `preview` with no edits | ≤ **60 s** | Warm caches |

Total ≤ 10 minutes: the user's stated tolerance for a 1–3 minute video, measured at the top of that range. (Re-anchored September 24, 2026 from the 2-minute `emu_war` when the story fixtures became complete ~3-minute stories. The 6/4 split became 6.5/3.5, because planning scales with scene count while rendering is fast.) **Exceeding a bar is filed with the per-stage timings**, never fixed silently by lowering quality (fewer images, a smaller model, lower CRF). Those are the user's trade-offs to make.

## 6. Offline gate (`scripts/check_offline.sh`)

Enforces `design_system_architecture.md` §7 with macOS `sandbox-exec` and `scripts/offline.sb`:

```
(version 1)
(allow default)
(deny network-outbound)
(allow network-outbound (remote ip "localhost:*"))
(allow network-outbound (remote unix-socket))
```

1. **Self-check first:** inside the sandbox, `curl -sS -m 5 https://example.com` must **fail** and `curl -sS -m 5 http://127.0.0.1:11434/api/tags` must **succeed**. If either does not hold, exit 1: the sandbox is not doing what the gate assumes.
2. With `HF_HUB_OFFLINE=1`, `INFOGRAPHICS_CACHE_DIR=<fresh temp dir>` (forces real image generation and real LLM calls), and a fresh jobs dir: `new molasses_flood.txt` → `approve` → `render` inside the sandbox → all **0**.

`sandbox-exec` is deprecated but functional on current macOS. If it stops working, file it; do not delete the gate.
