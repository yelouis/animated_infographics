# Data Contracts

This document owns the **shape of every JSON file** the pipeline writes, which side is the **source of truth**, how the TypeScript side is **generated**, and the **sync gate** that keeps the two sides from drifting.

---

## 1. Source of truth and generation

**Pydantic v2 models in `src/animated_infographics/contracts/` are the single source of truth.** Everything else is generated from them:

| Generated file | Generator | Consumer |
|---|---|---|
| `schema/{voice,transcript,bible,beats,storyboard,timeline}.schema.json` | `model_json_schema()` | Documentation, the renderer's runtime validation, the LLM `format` schemas |
| `renderer/src/generated/contracts.ts` | `json-schema-to-typescript` over `schema/timeline.schema.json` | Renderer types |
| `renderer/src/generated/templateRegistry.json` | `contracts/templates.py` registry | Renderer: text-slot typography, enter timings, SFX cues |
| `renderer/src/generated/iconNames.json` | `contracts/icons.py` allow-list | Renderer `Icon` component; the icon gate |

**Command:** `uv run python -m animated_infographics.contracts.export`. Every generated file starts with the header comment (or `"$comment"` key for JSON) `GENERATED by animated_infographics.contracts.export — DO NOT EDIT`.

**Why Python is the source.** The planner writes these files and the validators enforce them, so a human edit and an LLM output are both checked against the Python models. If TypeScript were the source, a skipped regeneration would leave the *validators* stale. Invalid plans would then pass review and fail at render time, after the human approved them.

**Sync gate: `scripts/check_schema_sync.sh`.** Regenerates every file above into a temp directory and diffs against the committed copies. Exit 1 on any difference. **It must refuse to report success if any compared file is empty or missing on either side.** A generator that silently emits nothing would otherwise make both sides equally empty and the gate would pass vacuously.

**Model config (all models):** `model_config = ConfigDict(extra="forbid", frozen=True)`. A typo in a hand-edited field must fail loudly, never be ignored.

**Versioning:** every top-level file carries `"schema_version": 1`. Loaders reject any other value with exit code 2. A breaking change bumps the version and ships a migration note in the commit body; there is no silent upgrade.

**Time units:** milliseconds (`*_ms`, integers) everywhere in Python-authored files **except `timeline.json`, which is in frames** (`*_frame`, integers, 30 fps). The conversion happens in exactly one place: `timing/frames.py` (`design_audio_and_timing.md` §6).

## 2. `transcript.json`

```json
{
  "schema_version": 1,
  "source": "tts",
  "audio_path": "audio/narration.wav",
  "duration_ms": 52340,
  "words": [
    {"i": 0, "text": "The", "start_ms": 0, "end_ms": 180, "sentence_i": 0}
  ],
  "sentences": [
    {"i": 0, "text": "The Great Molasses Flood", "start_ms": 0, "end_ms": 1420,
     "word_start": 0, "word_end": 4, "paragraph_i": 0, "is_title": true}
  ]
}
```

- `source` ∈ `tts` · `asr`.
- `words[].text` carries attached punctuation (`"1919,"`, `"syrup."`). Rules are in `design_audio_and_timing.md` §4.
- `word_end` is **exclusive**.

**Invariants (checked on load; violations are exit 2):**
1. `words` indexed `0..n-1` in order; `end_ms > start_ms`; `start_ms[i] >= end_ms[i-1]`.
2. `sentences` partition `words` exactly, contiguous and in order.
3. `duration_ms >= words[-1].end_ms`.
4. At most one sentence has `is_title: true`, and if present it is sentence 0.

## 3. `bible.json` (human-editable)

```json
{
  "schema_version": 1,
  "title": "The Great Molasses Flood",
  "logline": "A leaking tank of molasses bursts and floods Boston's North End.",
  "genre": "history",
  "cast": [
    {"id": "c1", "name": "Rescuers", "role": "Sailors and firefighters", "is_narrator": false,
     "color_slot": 1,
     "avatar": {"skin": 2, "hair_style": "short", "hair_color": "brown", "facial_hair": "none",
                "headwear": "military_cap", "glasses": false, "age": "adult"}}
  ],
  "places": [
    {"id": "p1", "name": "Boston", "kind": "real", "country_iso3": "USA",
     "lat": 42.35843, "lon": -71.05977, "geo_source": "gazetteer",
     "visual_description": "Brick warehouses and an elevated railway on a 1919 harbor street",
     "icon": "Buildings"}
  ],
  "set_pieces": [
    {"id": "v1", "name": "The molasses tank",
     "visual_description": "A huge cylindrical steel tank splitting open, dark syrup pouring out",
     "icon": "Drop"}
  ]
}
```

| Field | Constraint |
|---|---|
| `title` | 1–60 chars |
| `logline` | 1–140 chars |
| `genre` | `history` · `personal_story` · `other` |
| `cast` | 0–8 items; `id` matches `^c[1-8]$`, unique; `name` 1–24; `role` 1–40; **at most one** `is_narrator: true`; `color_slot` 0–7, **unique across cast** |
| `avatar.skin` | 0–5 |
| `avatar.hair_style` | `short` · `long` · `bun` · `curly` · `ponytail` · `bald` |
| `avatar.hair_color` | `black` · `brown` · `blonde` · `red` · `gray` · `white` |
| `avatar.facial_hair` | `none` · `beard` · `mustache` |
| `avatar.headwear` | `none` · `hat` · `crown` · `military_cap` · `helmet` · `headscarf` |
| `avatar.glasses` | bool |
| `avatar.age` | `child` · `adult` · `elder` |
| `places` | 0–4 items; `id` `^p[1-4]$`; `name` 1–40; `kind` `real`·`fictional`; `country_iso3` `^[A-Z]{3}$` or null; `lat` −90..90 or null; `lon` −180..180 or null (both null or both set); `geo_source` `gazetteer`·`llm`·`none`; `visual_description` 1–200; `icon` ∈ icon allow-list |
| `set_pieces` | 0–3 items; `id` `^v[1-3]$`; `name` 1–40; `visual_description` 1–200; `icon` ∈ allow-list |

**Cast members are always drawn as vector avatars, never as generated images.** This is what makes "persistent cast" hold: the same person must look identical in `character_intro`, `dialogue` and `emotion_beat`. A generated portrait cannot change expression and would drift between scenes. Generated images are only for places and set pieces (`design_visual_direction.md` §7).

## 4. `beats.json`

```json
{"schema_version": 1,
 "beats": [{"i": 0, "word_start": 0, "word_end": 4, "start_ms": 0, "end_ms": 2210, "text": "The Great Molasses Flood"}]}
```

Beats **tile** the narration: `beats[0].start_ms == 0`, `beats[k].end_ms == beats[k+1].start_ms`, and the last `end_ms == words[-1].end_ms`. `word_end` is exclusive. Beats are machine-owned. **Beat boundaries are not human-editable in the MVP**; editing them is a deferred feature.

## 5. `storyboard.json` (human-editable)

```json
{
  "schema_version": 1,
  "aspect": "9:16",
  "scenes": [
    {"id": "s000", "beat_i": 0, "template": "title_card",
     "props": {"title": "The Great Molasses Flood", "subtitle": "Boston, 1919", "icon": "Drop"},
     "mute_sfx": false,
     "rationale": "Opening title."}
  ]
}
```

- **Exactly one scene per beat, in beat order.** `id` = `s` + zero-padded 3-digit beat index.
- `template` ∈ the 16 names in `design_templates.md`; `props` must validate against **that template's** props model (a discriminated union on `template`).
- `mute_sfx` suppresses that scene's SFX cues.
- `rationale` 0–140 chars: why the planner chose this template. It is shown in `preview/storyboard.md` and ignored by the renderer.
- `aspect` is the literal `"9:16"` in the MVP.

**What a human may change:** `template` (with matching `props`), any `props` value, `mute_sfx`, `rationale`, and anything in `bible.json`. **What they may not:** `id`, `beat_i`, scene count, scene order. `preview` rejects those with exit 2.

## 6. `plan_report.json`

Written by the planner; read by `status`, the planner eval and `preview/storyboard.md`.

```json
{"schema_version": 1, "model": "gemma4:26b", "llm_calls": 31, "llm_cache_hits": 0,
 "scenes": [{"id": "s004", "primary": "stat_callout", "alternate": "kinetic_quote",
             "final_template": "stat_callout", "fallback_level": 0, "attempts": 1, "errors": [],
             "critic": {"status": "not_applicable", "mismatches": [], "changed": false}}],
 "rule_repairs": [{"rule": "R2", "scene": "s009", "from": "dialogue", "to": "emotion_beat"}]}
```

`fallback_level`: `0` primary template accepted · `1` alternate template used · `2` deterministic `kinetic_quote` fallback.

`critic` (added September 25, 2026, Issue 5): `status` ∈ `not_applicable` · `agree` · `mismatch_retried` · `unavailable`; `mismatches` lists `"<field>: <props value> vs <critic value>"`; `changed` is true iff the retry replaced the scene. Rules: `design_planner.md` §11.

## 7. `timeline.json` (renderer input)

The **only** file the renderer reads. It is fully resolved: frame numbers, asset paths relative to the render public directory, and dictionaries for every referenced entity. **A template never needs anything outside `timeline.json`.**

```json
{
  "schema_version": 1,
  "fps": 30, "width": 1080, "height": 1920,
  "duration_frames": 1616,
  "plan_sha256": "…",
  "debug": {"sync_probe": false},
  "audio": {
    "narration": {"src": "job/audio/narration.wav"},
    "music": {"src": "job/audio/music.wav", "volume": 0.126, "fade_in_frames": 30, "fade_out_frames": 60},
    "sfx": [{"src": "job/audio/sfx/pop_0.wav", "frame": 212, "volume": 0.35}]
  },
  "cast": {"c1": {"name": "Maya", "color": "#2A9D8F", "avatar": {"skin": 1, "…": "…"}}},
  "places": {"p1": {"name": "Boston", "image": "job/assets/images/p1.png", "icon": "Buildings",
                    "lat": 42.35843, "lon": -71.05977, "country_iso3": "USA"}},
  "set_pieces": {"v1": {"name": "The molasses tank", "image": null, "icon": "Drop"}},
  "scenes": [
    {"id": "s000", "template": "title_card", "start_frame": 0, "end_frame": 60,
     "hide_captions": true, "timing": {"item_frames": [], "count_frames": null},
     "props": {"title": "The Great Molasses Flood", "subtitle": "Boston, 1919", "icon": "Drop"}}
  ],
  "captions": {"pages": [
    {"start_frame": 66, "end_frame": 101,
     "words": [{"text": "On", "start_frame": 66, "end_frame": 72}]}]}
}
```

- `music` is `null` when no `--music` was given; `sfx` is `[]` when no `--sfx-dir` was given.
- `image: null` means "no image available": the template renders its icon fallback.
- Scenes tile `[0, duration_frames)`: `scenes[0].start_frame == 0`, `scenes[k].end_frame == scenes[k+1].start_frame`, `scenes[-1].end_frame == duration_frames`. How a scene's visible span extends past `end_frame` for its exit animation is in `design_rendering.md` §4.
- `timing.item_frames` (frames relative to scene start, one per list item/marker/line/message/event) and `timing.count_frames` (`stat_callout` only; otherwise null) are computed **in Python** by `compile.py`. The renderer uses them for entrances and `compile.py` uses them for SFX cues, so sound and picture share one number (`design_templates.md` §1 rule 5).
- `props` are the storyboard props unchanged (ids, not inlined objects). Templates resolve ids through the `cast` / `places` / `set_pieces` dictionaries via a context hook.

**Renderer-side validation:** the `Story` composition's `calculateMetadata` validates `inputProps` against `schema/timeline.schema.json` (Ajv) and **throws** on failure. A render never starts on an invalid timeline.

## 8. Template registry (`contracts/templates.py`)

One entry per template. It is the single place a template's contract is declared:

```python
TemplateSpec(
    name="stat_callout",
    category="statement",            # statement | people | place_time | fallback
    props_model=StatCalloutProps,    # Pydantic; maxLength etc. live here
    use_when="A specific number is the point of the beat: a count, amount, size, speed, percentage.",
    writing_rules=["value must be a number said in this beat", "caption ≤ 70 chars, plain words"],
    slots={"value": TextSlot(font="display", weight=800, size_max=200, size_min=110, max_lines=1, box_width=940),
           "suffix": TextSlot(font="display", weight=700, size_max=64, size_min=44, max_lines=1, box_width=900),
           "caption": TextSlot(font="body", weight=600, size_max=44, size_min=32, max_lines=3, box_width=860)},
    sfx_cues=[SfxCue(role="ding", at="count_end")],
    requires={"cast": False, "places": False, "set_pieces": False, "geo": False},
)
```

The per-template values live in `design_templates.md`; the registry encodes them. **The renderer reads slot typography from `templateRegistry.json` and must not hard-code a font size that the registry declares.** Otherwise the Pillow fit check (`design_planner.md` §7) and the pixels on screen would measure different things.

## 9. `voice.json` (text input only)

Written by the `voice` stage before narration; read by `narrate`, `bible` (narrator avatar repair) and `preview` (the storyboard header line). Shape, enums and the decision rule: `design_planner.md` §10.

**Invariants (checked on load):** `source == "flag"` ⇔ `reason == "flag"` ⇔ `perspective`, `first_person_rate`, `narrator_gender` and `evidence` are all null. `voice ∈ INSTALLED_VOICES`. If `reason ∈ {tag, llm}`, then `evidence` is non-null and `narrator_gender ∈ {female, male}`. If `reason == "third_person"`, then `perspective == "third_person"`. `voice == "af_heart"` with `source == "auto"` ⇔ `perspective == "first_person"` and `narrator_gender == "female"`.

Not human-editable. Changing the voice means a new job with `--voice` (`design_planner.md` §10).
